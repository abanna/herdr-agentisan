# Standing facts for a boss shift

Copy this to the shift record root as `STANDING.md` and link each fact's source.

- Working rules and shift script — paths to the current rules and installed script.
- Shift board and owner questions — current document IDs and archive pointers.
- Live sources — worker status, exact PR heads and checks, inbox, lane and lock logs.
- Shared test lock — who holds it, how to check a long hold, and the source for each exception.
- Past corrections — current rule, dated owner decision and link to the original correction.
