# ADR-001 A51. The CLI finds the daemon from any pane

*Adds to:* D6, A23 and A30. *Overrides:* A41's sentence that rejected deriving herdr's state directory in Go, for the commands that ask a running daemon. Recorded with NERD-5256, from B-Q5 of NERD-5261's Stage 3.

- **Why.** herdr sets `HERDR_PLUGIN_STATE_DIR` only for the plugin's own processes and panes (herdr 0.9.5 `src/app/api/plugins/env.rs:15-30`), never for a shell in one of its panes. A pane shell's `HERDR_*` variables are `BIN_PATH`, `ENV`, `PANE_ID`, `SOCKET_PATH`, `TAB_ID` and `WORKSPACE_ID`. Every command found the daemon by `--state-dir` or that variable, so from a pane, where every worker and the boss run them, `send`, `team status` and `worker retire` failed `daemon_unavailable`, and `back`, `dashboard` and `daemon health` failed with no state directory. A41 kept the derivation out of Go to keep the plugin off herdr's internal layout. With every worker's command broken without it, the plugin takes that dependency, pinned to one herdr version and checked where it can be.
- **The rule.** A command's state directory is `--state-dir`, else `HERDR_PLUGIN_STATE_DIR`, else herdr's own for this plugin (`plugin.StateDir`), worked out from the command's environment as herdr 0.9.5 does:
  - `$XDG_STATE_HOME/herdr/plugins/nerdsrun.agentisan` when `XDG_STATE_HOME` is set at all, else `$HOME/.local/state/herdr/plugins/nerdsrun.agentisan` (`src/plugin_paths.rs:50-54`, `src/config/io.rs:37-42,88-94`).
  - herdr reads both with `std::env::var`, so a set but empty value counts, and gives a relative directory that the daemon's paths refuse, and a value that is not UTF-8 does not count. The tab-bar snippet's `${XDG_STATE_HOME:-…}` takes an empty one as unset; the two differ only where herdr itself has no usable directory.
  - With neither variable there is no default, and the command refuses as before. herdr would fall back to its platform's temporary directory, but a pane shell always has `HOME`.
  - herdr escapes the plugin id into the last component (`src/plugin_paths.rs:96-124`). `nerdsrun.agentisan` is its own escape, and `TestIDIsItsOwnHerdrPathComponent` keeps it so.
  - `HERDR_ENV` is not an input. herdr sets it to `1` in its panes and plugin processes, and reads it only to refuse nesting and self-update. A tab-bar command does not get it, so the default does not wait for it either. Outside herdr, `HERDR_SOCKET_PATH` is unset and the daemon's paths refuse as before.
- **Which commands.** Those that ask or signal a running daemon: `send`, `team status`, `worker retire` and every later workforce op, which share one path to the daemon (part 4's `worker spawn` among them), and `back`, `dashboard`, `status line`, `daemon health` and `daemon stop`. A workforce op that finds no daemon under a derived directory says the directory was worked out, and to pass `--state-dir` if herdr runs with another.
- **Never a daemon's own start.** `daemon start`, `run` and `restart` keep `--state-dir` or `HERDR_PLUGIN_STATE_DIR`, which herdr's startup hook and the `daemon-restart` action both have. A daemon started under a wrong guess would take a lock in another directory: a second daemon for the same herdr server (against D3), and both would type every message (against I3's exactly once).
- **What it cannot see.** The derivation reads the command's environment, not the herdr server's. A pane whose `XDG_STATE_HOME` or `HOME` differs from the server's, a debug build of herdr (whose directory is `herdr-dev`, `src/config/io.rs:22-27`), or a remote attach gets a directory with no daemon in it, and so the answer there was before: a workforce op and `daemon health` refuse, naming the directory they tried, `back` fails as with no daemon running, `status line` prints `agentisan: daemon down`, the dashboard waits for the daemon, and `daemon stop` finds none to stop. A herdr release that moves the directory does the same until this rule follows it.
- **The tab bar.** Its snippet keeps `--state-dir` (A41): the flag still wins, `TestTabBarSnippet` runs the line, and herdr's config is the user's to edit.
