# ADR-001 A56. The model column follows a `/model` switch

*Overrides:* A39's "The launch model" bullet. *Adds to:* D4's token contract, A27 and A39. Recorded with Draft 24 (part of NERD-5319), from the user's report of 2026-10-22: after a `/model` switch to Sonnet or Haiku, the dashboard still showed Opus. The snapshot contract v1 is unchanged, but a row's `model` now means the model the pane's current agent last reported, else its launch model. A39's text is kept as written.

- **The tokens.** An agent reports the model it runs as the pane token `model`, and when it reported it as `model_at`, in Unix milliseconds, since herdr gives no token a time.
  - Both ride the agent's `ctx` report, with its source and TTL.
  - `report statusline` takes Claude's statusline `model.id`, with a 180 s TTL. Claude runs the statusline at session start and on events such as a new assistant message, and also on a timer when `refreshInterval` is set. This team's statusline sets it to 60 s.
  - `report codex` takes a Codex hook's `model`, which Codex fills from the turn's model, with a 24 h TTL (A27).
  - A report with no context yet pushes the model alone. Malformed input pushes nothing, the model included.
  - The model is kept only when A39's rule keeps it: printable UTF-8, at most 80 code points, not a flag. Both sides use the same function, `report.ValidModel`.
  - A model of any other shape is no model, never malformed input, so it cannot silence ctx.
  - Neither `report turn` nor the daemon writes either key, so each key has one writer.
- **The preference.** The daemon reads a pane's model only while herdr detects an agent in the pane, as for ctx (A27), and only with a `model_at` as the report writes it.
  - It is the row's model when it was reported no earlier than the pane's agent process started. That start is the one A47 puts on the wall clock.
  - Otherwise the row has A39's launch model, and failing that, none. So a Codex restarted with another `-m` shows its launch model, never the 24 h token its previous session left.
  - Where no start is known, the reported model counts. That covers a miss, a pane the 1 s budget left out that poll, and an OS with no start time.
  - The rule is `team.CurrentModels`; the poll only wires it.
- **The clock.** A47's start on Linux is `btime`, whole seconds rounded down, plus the start's ticks, so it is never after the true start.
  - A report made after the agent started is therefore never read as older than it.
  - The stamp is in milliseconds, not `stage_at`'s seconds, so that a report made within a second of the start is not truncated to before it.
  - A report made in the second before a new agent started could read as the new agent's. That needs one agent to exit and the next to start in under a second, and the new agent's own next report corrects it.
- **When it shows.**
  - A Claude `/model` shows at the next statusline run, then at the next poll. `/model` itself is not a statusline event, so an idle Claude shows it within 60 s only when its statusline sets `refreshInterval: 60`, as this team's does. Otherwise it shows at the next assistant message.
  - Without a refresh interval, an idle Claude's `model` token expires with ctx's 180 s TTL, and the row falls back to its launch model until the next statusline run.
  - A Codex `/model` shows after its next tool use, turn end or compaction.
  - An agent started with no model flag shows the model it reports, so A39's "an agent started with no flag shows none" holds only until its first report.
- **Unchanged.** A39's asks and cache, which A47's start rides on; the dashboard's `ShortModel`; `team status`, which carries no model; and the sidebar, which shows none.
