# ADR-001 A53. A repo file's empty entries, a group's name, and the launch limits

*Refines:* A46's "Set means present". *Adds to:* D9's profile (a group's name) and A23's configuration that `worker spawn` reads (the launch-flag limit and the shell prompt's two regex dialects). Recorded with NERD-5369: the QA debt of #64 (A46) and the items NERD-5352 carried.

- **An empty entry.** A46's "a table that sets no leaf passes" still holds for a fixed table, such as `[spawn]` or a group's `[agent]`: it sets nothing.
  - A table that adds an entry to a table of names does add something. An empty `[integrations.x]`, or `integrations = { x = {} }`, adds an integration `x` with no url or token.
  - So a repo file's empty entry is refused unless its path leads to a key a repo file may set. An empty `[groups.x]` leads to a group's `workers`, so it is still a group, which then needs its counts.
  - The error is A46's, naming the entry. It lists the keys a repo file may set, built from `repoFileKeys`, so the two cannot drift.
- **A group's name.** At most 20 characters, from any layer.
  - Anything longer is `ErrInvalid`, naming the group with the layer and file of its first key.
  - Why 20: a worker's id, `<short>-<group>-<n>`, is its agent's name, which herdr caps at 32 characters. With a short code of at most 8 characters (A19) and n up to 99, a group of 20 fits.
  - Spawn still checks each whole id (`ErrInvalidID`), since past n = 99 an id can still be too long.
  - Project and integration names stay unbounded: neither becomes an agent's name.
- **The launch-flag limit.** A23's refused flags stand.
  - A command may still name a model through a codex `-p`/`--profile` or a claude `--settings` file, and is not refused for it. By each CLI's own precedence, the `--model` the workforce passes outranks both:
    - Codex ranks "CLI flags and `--config` overrides" before profile files.
    - Claude Code ranks `--model` at startup before a settings file's `model`.
  - With no model set, the command's own configuration decides, and a command comes only from the user's own layers (A46).
  - An abbreviated flag such as `--mod` is no `--model`, so it is not refused either. Claude's parser matches long flags whole, and codex-cli 0.161.0 refuses `--mod` as an unexpected argument.
- **The shell prompt's two dialects.** herdr matches `spawn.shell_prompt` with Rust's `regex`, and resolve compiles it with Go's `regexp`.
  - A23 records one direction: a construct Rust lacks passes resolve and fails the spawn.
  - The other direction: a construct Go lacks, such as `(?x)` or a repeat past 1,000 (`a{1001}`), is refused at resolve, though herdr would take it.
  - A pattern both compile can still match differently: Rust's `\d`, `\w`, `\s` and `\b` match Unicode, Go's only ASCII.
- **Decided without code** (NERD-5352's carried items, all on main already):
  - The bare-name rule lives in spawn: resolve accepts a command named by a path, and spawn refuses it (A23).
  - A group that only describes takes no agent (`checkDescribers`, A36).
  - Spawn names `spawn.shell_prompt` when herdr refuses the pattern as `invalid_regex`.
