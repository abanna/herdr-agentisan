# ADR-001 A75. Dashboard navigation and data age

*Amends:* A18's mouse handling, A38's data-age display and A60's board
navigation. Tracked in NERD-5255.

- An upward or downward mouse wheel event acts as the matching arrow in
  the overview, group view and board. In an expanded post it scrolls the
  body. Horizontal wheel events do nothing.
- In the dashboard, `m` invokes the same btop popup as the header button.
  In an active search, it goes into the query. herdr's sample `prefix+m`
  binding opens a 92% by 92% btop popup from any pane.
- The footer's snapshot age still appears above 15 whole seconds. It
  displays seconds below a minute and uses the stage-age format from a
  minute onward, for example `data 43d09h old`.
