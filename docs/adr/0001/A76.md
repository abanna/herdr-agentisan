# ADR-001 A76. Dashboard text contrast and selection

*Amends:* A18's overview selection, A37's group selection, A42's stale
stage styling and A60's board selection. Tracked in NERD-5255.

**User decision, 2026-11-22:** “A: cool bar”.

- The dashboard's text palette uses explicit foregrounds. Each palette
  colour has at least 4.5:1 contrast on both `#1e1e2e` and `#000000`
  before terminal colour downsampling. The btop button pairs dark text
  with the light accent. The configured project colour remains the
  project's identifying accent.
- Stale stages use the secondary foreground and italic. The report age
  still identifies a stale stage when text attributes are unavailable.
- Colour terminals show a cool blue selection bar (`#36476b`). It spans
  the inside of the selected worker row and selected board post, including
  its visible expanded lines. In a group card, it highlights the title.
  Selected text keeps its foreground colour.
- On monochrome output, including `NO_COLOR`, a pointer marks the
  selected overview worker, group card or board post. It replaces a
  cell beside the content and preserves the column positions. A scrolled
  expanded post shows the pointer on its first visible line.
