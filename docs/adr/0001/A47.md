# ADR-001 A47. The boss's runtime from its agent process

*Overrides:* A31's "The boss's runtime" bullet. *Adds to:* A18's snapshot contract and A39's cache. Recorded with NERD-5349, #36's QA debt. The snapshot contract v1 is unchanged: `boss.started_at` stays optional RFC 3339. A31's text is kept as written.

- **The start.** `boss.started_at` is when the boss's agent process started: the process A39 finds in the boss pane's `pane.process_info` (argv[0] `claude` or `codex`, or `node` running codex), with or without a model flag, and the start time `Hooks.StartTime` reads for it. So the runtime is that agent session's. A `/clear` keeps it, since the process is the same. A new session in the pane, or a handoff to another pane, starts it again at the new process's start. A daemon restart reads the same process's start again, so the runtime goes on from where it was. Workers carry none.
- **The wall clock.** `Hooks.StartedAt` puts a start on the wall clock: on Linux, `/proc/stat`'s `btime` plus the start's clock ticks at USER_HZ, which the /proc ABI fixes at 100, as `ps` does; on darwin the start is already microseconds since the epoch; elsewhere there is none (`report.SystemStartedAt`). `btime` is whole seconds and is read again for each new process, so a daemon restart can move a start by up to about a second. The header shows minutes.
- **Read once.** The start rides on A39's cache entry: a poll puts it on the wall clock once, and it keeps that time while the entry holds, so it never moves from poll to poll. A conversion that fails is tried again at the next poll.
- **No guess (the user's decision, 2026-10-21).** When the start cannot be read, the boss has no `started_at`, and the header shows no runtime. That covers a pane where no agent process is found, an ask that failed or ran past A39's 1 s budget, a start time or boot time that cannot be read, and an OS with neither. It is never the daemon's first sight of the pane, which a restart would reset. A miss is asked again on A39's schedule, 60 s later.
- **The stage clock** keeps only the stages (A18). Its boss map, which A31 described, is gone.
